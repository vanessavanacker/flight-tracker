One-time setup

You'll need a Firebase Realtime Database (free) and a RapidAPI key for AeroDataBox (free, 500 lookups/month).

```
If you've already set this up on another device, leave blank — the app will pull the key from Firebase.
How do I get these?
Firebase URL:
1. Go to console.firebase.google.com
2. Add project → name it (e.g. "flight-tracker") → create.
3. Left sidebar → Realtime Database → Create Database → choose test mode.
4. Copy the URL shown — looks like https://flight-tracker-xxxxx-default-rtdb.firebaseio.com

RapidAPI Key:
1. Go to AeroDataBox on RapidAPI → Subscribe → pick the free Basic plan.
2. Click any endpoint → copy the X-RapidAPI-Key from the code sample.
```
